SPB Renovations

Digital Ownership Setup Guide

Prepared for the Business Owner  ·  Confidential

This guide walks through setting up and transferring ownership of all digital accounts for SPB Renovations. The goal is for the business owner to hold ownership of every account, with the developer added as a collaborator to continue development and management work. Follow each section in order — some steps require the developer to act first before the owner can complete them.

1

Instagram

Business Owner — Create the Account

  1. Download the Instagram app on your phone.
  2. Tap Sign Up and use the business email (contact@spbrenovations.com) as the account email.
  3. Set the username to @spbrenovations (or the closest available variation).
  4. Switch to a Business account: go to your Profile → Settings → Account → Switch to Professional Account → select Business.
  5. Fill in the business category (Home Improvement Contractor), phone number, and website.

Add Developer as Collaborator

  1. From your Profile, go to Settings → Business → Instagram Partners.
  2. Alternatively, use Meta Business Suite (business.facebook.com) once your Facebook Page is set up (see Section 2) to manage both accounts from one place.
  3. Add the developer's email or Meta account and grant partner/admin access.
2

Facebook

Business Owner — Create a Facebook Page

  1. Log into Facebook (or create a personal account at facebook.com if you don't have one).
  2. Click the + icon in the top right → Page.
  3. Page name: SPB Renovations
  4. Category: Home Improvement Contractor
  5. Fill in phone number, website (spbrenovations.com), and business hours.

Add Developer as Admin

  1. Go to your Page → click Manage (top right).
  2. Go to Page Access in the left sidebar.
  3. Under People with Facebook Access, click Add New.
  4. Search for the developer by name or email and grant Full Control.
  5. The business owner remains the primary admin — this does not change ownership.

Link Instagram to Facebook

  1. From the Facebook Page → Settings → Linked Accounts → connect your Instagram account.
  2. This enables unified management through Meta Business Suite (business.facebook.com).
3

Mux (Video Hosting for Gallery)

Business Owner — Create the Account

  1. Go to mux.com → click Sign Up.
  2. Use the business email: contact@spbrenovations.com.
  3. During onboarding, select Video as the product.
  4. Add a payment method — there is a free tier to start, but a card is required to activate the account.

Add Developer as Team Member

  1. In the Mux dashboard, go to Settings → Organization → Members.
  2. Click Invite Member and enter the developer's email.
  3. Assign role: Admin (so the developer can upload and manage videos).
  4. The developer will receive an email invitation to join the workspace.
Uploading videos: Once the account is set up, go to Mux Dashboard → Video → Assets → Upload Video and drag your video files directly. The developer will handle connecting uploaded videos to the website gallery.
4

Resend (Contact Form Email Service)

Resend is the service that delivers contact form submissions from the website to your inbox. The business owner should own this account.

Business Owner — Create the Account

  1. Go to resend.com → click Sign Up.
  2. Use the business email: contact@spbrenovations.com.

Verify the Domain

  1. In the Resend dashboard, go to Domains → Add Domain.
  2. Enter spbrenovations.com.
  3. Resend will display a set of DNS records — copy these and add them in GoDaddy (see Section 7).
  4. Return to Resend and click Verify. This can take a few minutes to a few hours.

Get an API Key

  1. Go to API Keys → Create API Key.
  2. Name it SPB Renovations Production.
  3. Copy the key and send it securely to the developer — it will be added to the website's hosting settings (Vercel).

Add Developer as Team Member

  1. Go to Settings → Team → Invite Member.
  2. Enter the developer's email → assign role: Admin.
5

GitHub (Website Source Code)

Business Owner — Create an Account

  1. Go to github.com → click Sign Up.
  2. Use the business email: contact@spbrenovations.com.
  3. Choose the Free plan.

Create a GitHub Organization (Recommended)

  1. Once logged in, click the + icon (top right) → New Organization.
  2. Name it spb-renovations → choose the Free plan.
  3. Skip adding members for now — the developer will handle this in the next step.

Developer — Transfer the Repository

  1. The developer goes to the existing repository on GitHub → Settings.
  2. Scroll to the Danger Zone → click Transfer Repository.
  3. Type the repository name to confirm, then transfer it to the spb-renovations organization just created.

Add Developer as Collaborator

  1. In the GitHub organization, go to People → Invite Member.
  2. Enter the developer's GitHub username → assign role: Owner (so they can continue development).
6

Vercel (Website Hosting)

Business Owner — Create an Account

  1. Go to vercel.com → click Sign Up with GitHub using the GitHub account created in Section 5.
  2. This automatically links Vercel to the GitHub organization.

Create a Vercel Team

  1. In the Vercel dashboard, click your avatar → Create Team.
  2. Name it SPB Renovations.
  3. Choose the Hobby (free) plan to start — upgrade to Pro if needed later.

Developer — Transfer the Project

  1. The developer goes to the existing Vercel project → Settings → Transfer Project.
  2. Transfer to the business owner's SPB Renovations team.
  3. After transfer, re-link the project to the GitHub repository: go to project Settings → Git → reconnect to the repo in the spb-renovations GitHub org.

Re-add Environment Variables

  1. In the transferred project, go to Settings → Environment Variables.
  2. Add the following variable:
    Key: RESEND_API_KEY  ·  Value: the API key from Section 4.

Add Developer as Collaborator

  1. Vercel team → Settings → Members → Invite.
  2. Enter the developer's email → assign role: Admin.
7

GoDaddy (Domain & DNS)

The business owner already owns the GoDaddy account and the domain spbrenovations.com. This step grants the developer access to manage DNS records.

Add Developer via Delegate Access

  1. Log into GoDaddy → click your account name in the top right → Account Settings.
  2. Go to Delegate Access → click Grant Access.
  3. Enter the developer's email address.
  4. Set access level to Full Access (required to manage DNS records for domain verification).
  5. The developer will receive an email invitation to accept.
Why this matters: DNS records in GoDaddy need to be updated to connect the domain to Vercel (for hosting), to verify the domain in Resend (for email delivery), and potentially for Google Business verification. Developer access makes these updates possible without requiring the business owner's login each time.
8

Google Business Profile

Business Owner — Create the Profile

  1. Go to business.google.com and sign in with a Google account (use contact@spbrenovations.com or your personal Gmail).
  2. Click Add your business → enter SPB Renovations.
  3. Category: Home Improvement Contractor
  4. Add phone number, website, service area (Tampa Bay), and business hours.
  5. Click Verify — Google will mail a postcard to the business address with a verification code. This typically takes 5–7 days.

Add Developer as Manager

  1. In Google Business Profile → Business Profile Settings → Managers.
  2. Click Add → enter the developer's Google/Gmail address.
  3. Assign role: Manager.
9

Business Email (contact@spbrenovations.com)

This email address is used across the website and all accounts above. It needs to be set up as a real, working inbox so contact form submissions and inquiries are actually received.

Option A — Google Workspace (Recommended, ~$6/month)
  1. Go to workspace.google.com → Start Free Trial.
  2. Enter domain spbrenovations.com during setup.
  3. Google will provide DNS records — add them in GoDaddy (see Section 7).
  4. This creates a full Gmail inbox at contact@spbrenovations.com.
Option B — GoDaddy Email Hosting
  1. Log into GoDaddy → go to Email & Microsoft 365.
  2. Purchase a Professional Email plan for your domain.
  3. Less feature-rich than Google Workspace, but simpler to manage if you prefer to stay within GoDaddy.
